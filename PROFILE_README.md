## More projects

### Systems and protocols

- **[mvccdb](https://github.com/rushikeshg25/mvccdb)**: A sharded in-memory key-value store with lock-free version chains, snapshot isolation, and a group-commit WAL.
- **[tlshake](https://github.com/rushikeshg25/tlshake)**: A TLS 1.3 client implemented from scratch in Go, including the record layer and key schedule.
- **[cdc](https://github.com/rushikeshg25/cdc)**: A PostgreSQL change-data-capture engine built directly on logical replication and `pgoutput`.
- **[coil](https://github.com/rushikeshg25/coil)**: A small bytecode language with closures and a tricolour mark-and-sweep garbage collector.
- **[mini-headless-browser](https://github.com/rushikeshg25/mini-headless-browser)**: A browser pipeline built without Chromium that renders HTML and CSS as terminal ASCII.
- **[cool-db](https://github.com/rushikeshg25/cool-db)**: A persistent SQL database with its own parser, execution engine, gRPC server, and interactive shell.
- **[wal-go](https://github.com/rushikeshg25/wal-go)**: A thread-safe write-ahead log with file rotation and integrity checks.
- **[task-scheduler](https://github.com/rushikeshg25/task-scheduler)**: A concurrent Go scheduler with priorities, retries, periodic tasks, a worker pool, and a live TUI.
- **[shell](https://github.com/rushikeshg25/shell)**: A Unix-style shell implemented from scratch in C to explore operating-system internals.
- **[go-core-impl](https://github.com/rushikeshg25/go-core-impl)**: Foundational systems and data structures implemented from scratch in Go.
